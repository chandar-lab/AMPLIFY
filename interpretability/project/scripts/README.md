This folder contains scripts used for different parts of the pipeline

[linear_probe_results.sh](linear_probe_results.sh) launches jobs

[linear_predictions.py](linear_predictions.py) makes linear probe predictions on specified test sets for datasets listed at the beginning of the script, including appropriate controls to help figure out whether the probe is working, the plm embeddings contain information, or if just predicting the mean embedding would be effective at this task.

[prediction_metrics.py](prediction_metrics.py) takes linear probe predictions from [linear_predictions.py](linear_predictions.py) and computes metrics depending on the task type and task level for specified datasets and models (given at the beginning of the script).

[multi_layer_probe.sh](interpretability/project/scripts/launch_probe_training/multi_layer_probe.sh) launches linear probe training on given datasets and models using Hydra for orchestration, wandb for tracking and Lightning for ml.

[visualize_results.py](visualize_results.py) takes the metrics df generated by [prediction_metrics.py](prediction_metrics.py) and visualizes mean and elementwise metrics for specified datasets using plotly, outputting a set of html figures in the specified results directory.
